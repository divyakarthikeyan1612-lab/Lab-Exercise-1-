## a) EXPLORE THE FUNDAMENTALS OF UI AND UX

### User Interface (UI)

**User Interface (UI)** is the visual and interactive part of a digital product through which users interact with a system.

UI includes:

* Layout
* Colours
* Typography
* Icons
* Buttons
* Images
* Menus
* Visual elements

A good UI makes a product **clear, attractive, consistent, and easy to interact with**.

**Example:**
In a mobile banking application, the login screen, transaction icons, account information, and **Send Money** button are examples of UI elements.

### User Experience (UX)

**User Experience (UX)** refers to the overall experience a user has while interacting with a product or service.

UX focuses on:

* Usability
* Navigation
* Accessibility
* Efficiency
* Functionality
* User flow
* User satisfaction

A good UX allows users to complete their tasks **easily, quickly, and comfortably**.

**Example:**
In a banking application, UX ensures that sending money is simple, requires minimum steps, provides clear instructions, and displays a confirmation message.

### Difference Between UI and UX

| **UI**                                      | **UX**                                        |
| ------------------------------------------- | --------------------------------------------- |
| Focuses on visual appearance                | Focuses on overall user experience            |
| Includes colours, fonts, icons, and layouts | Includes usability, navigation, and user flow |
| Makes the product visually appealing        | Makes the product easy and satisfying to use  |
| Focuses on interface elements               | Focuses on the complete user journey          |
| Example: Design of a "Send Money" button    | Example: Ease of completing a money transfer  |

**Key Point:**

> UI focuses on **how a product looks**, while UX focuses on **how a product works and feels to the user**.

# c) ILLUSTRATE THE RELATIONSHIP BETWEEN UI AND UX IN DESIGN

UI and UX are closely connected in the design process.

* **UX** determines how the product works.
* **UI** determines how the product looks.
* UX focuses on user needs, usability, and task completion.
* UI presents the required functions through visual and interactive elements.
* Good UI supports good UX.
* Good UX helps determine what the UI should provide.

### UI/UX Design Flow

```text
User Research
      ↓
Identify User Needs
      ↓
UX Design
      ↓
Information Architecture
      ↓
User Flow
      ↓
Wireframe
      ↓
UI Design
      ↓
Prototype
      ↓
Usability Testing
      ↓
Final Product
```

### Example – Login Page

**UX:**
The user should be able to log in quickly and easily.

**UI:**
The login page contains:

* Application logo
* Email/Username field
* Password field
* Login button
* Forgot Password option
* Sign Up option

### Relationship

```text
Good UI
   ↓
Attracts and Guides Users
   ↓
Good UX
   ↓
Helps Users Complete Tasks Successfully
```

A visually attractive interface is not useful if it is difficult to use. Similarly, a functional product may not be effective if its interface is confusing.

Therefore, **UI and UX must complement each other**.
