# OUTPUT

## A) Fundamentals of UI and UX

### 1. User Interface (UI)

**User Interface (UI)** is the visual and interactive part of a digital product through which users interact with a system.

UI includes:

* Layouts
* Colours
* Typography
* Icons
* Buttons
* Images
* Menus
* Visual elements

A well-designed UI makes a product **visually appealing, clear, consistent, and easy to interact with**.

**Example:**
In a mobile banking application, UI includes the login screen, transaction icons, account information, and the **"Send Money"** button.

---

### 2. User Experience (UX)

**User Experience (UX)** refers to the overall experience a user has while interacting with a product or service.

UX focuses on:

* Usability
* Navigation
* Accessibility
* Efficiency
* Functionality
* User flow
* User satisfaction

A good UX allows users to complete their tasks **easily, quickly, and comfortably**.

**Example:**
In a banking application, UX ensures that sending money is simple, requires minimum steps, provides clear instructions, and displays a confirmation message after the transaction.

---

## Difference Between UI and UX

| **UI**                                      | **UX**                                        |
| ------------------------------------------- | --------------------------------------------- |
| Focuses on visual appearance                | Focuses on overall user experience            |
| Includes colours, fonts, icons, and layouts | Includes usability, navigation, and user flow |
| Makes the product visually appealing        | Makes the product easy and satisfying to use  |
| Focuses on interface elements               | Focuses on the complete user journey          |
| Example: Design of a "Send Money" button    | Example: Ease of completing a money transfer  |

### Key Point

> **UI focuses on how a product looks and interacts, while UX focuses on how the product works and feels to the user.**

# C) RELATIONSHIP BETWEEN UI AND UX

UI and UX are closely connected in the design process.

* **UX** determines how the product works and how users complete their tasks.
* **UI** determines how the product looks and how users interact with the interface.
* Good UX helps designers understand what the interface should provide.
* Good UI presents those functions in a clear and attractive way.

### UI

```text
Good UI
   ↓

   ↓
```

# D) UI/UX DESIGN TOOLS

Various tools are available for designing interfaces, creating wireframes, developing prototypes, and testing user experiences.

| **Tool**     | **Main Use**                  | **Strengths**                            | **Limitations**                     |
| ------------ | ----------------------------- | ---------------------------------------- | ----------------------------------- |
| **Figma**    | UI design and prototyping     | Browser-based, real-time collaboration   | Some features require internet      |
| **Adobe XD** | UI design and prototyping     | Good design and prototyping features     | Less actively developed             |
| **Sketch**   | UI design and prototyping     | Powerful plugins and design features     | Mainly designed for macOS           |
| **InVision** | Prototyping and collaboration | Interactive prototypes and feedback      | Limited compared with full UI tools |
| **Canva**    | Visual and interface design   | Easy drag-and-drop interface             | Not ideal for complex prototypes    |
| **Balsamiq** | Wireframing                   | Simple and quick low-fidelity wireframes | Not intended for detailed final UI  |

# FIGMA DEMONSTRATION

The following steps can be performed using **Figma**:

1. Open Figma and create a new design file.
2. Create a **Frame** for the required screen.
3. Add text, buttons, images, icons, and other UI elements.
4. Arrange the elements using proper alignment and spacing.
5. Apply suitable colours and typography.
6. Create additional screens if required.
7. Use the **Prototype** feature to connect the screens.
8. Preview the prototype.
9. Test the navigation between screens.
10. Make improvements based on the testing results.
